An ultra-lightweight, zero-bloat security endpoint utility and login screen visual customizer. Developed natively for professional agency client handoffs.

== Description ==

NGT Easy Login Customizer keeps your WordPress administration panel 100% clean. It completely avoids injecting messy admin menus, promotional banner alerts, or constant tracking dashboards. 

Instead, all properties interface directly inside the native WordPress Customizer panel, keeping backend workflows isolated and fast.

== Installation ==

1. Upload the ngt-easy-login-customizer.zip package within your Plugins dashboard panel.
2. Activate the plugin file.
3. Configure your portal branding and endpoints via the dedicated NGT Login Settings menu in the primary admin sidebar.
